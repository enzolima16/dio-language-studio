# DIO - Análise de Sentimentos com Azure Speech Studio e Language Studio

## Descrição
Este repositório foi desenvolvido como entrega do desafio prático da DIO com foco no uso do Azure Speech Studio e do Azure Language Studio. O objetivo do laboratório é praticar recursos de inteligência artificial aplicados à voz e à linguagem natural, registrando a experiência em um repositório público e organizado.

## Objetivos de aprendizagem
Durante a realização do desafio, os principais objetivos foram aplicar os conceitos vistos nas aulas em um ambiente prático, documentar processos técnicos com clareza e utilizar o GitHub como plataforma de compartilhamento da documentação técnica.

## Ferramentas utilizadas
- Azure Speech Studio, ambiente com interface gráfica para testar recursos de fala sem necessidade de código, incluindo cenários como conversão de fala em texto e outros recursos do serviço de Fala da Azure.
- Azure Language Studio, usado para explorar funcionalidades de análise de linguagem natural, como análise de sentimento e mineração de opiniões em textos.
- GitHub, utilizado para armazenar e versionar a documentação do laboratório em formato Markdown.

## Etapas realizadas
### 1. Exploração do Speech Studio
No Speech Studio, a proposta do laboratório é conhecer uma ferramenta visual para experimentar recursos de fala da Azure sem escrever código. A documentação da Microsoft descreve o Speech Studio como um conjunto de ferramentas baseadas em interface para criação e integração de funcionalidades do serviço de fala em aplicações.

Nesta etapa, a prática pode incluir testes de reconhecimento de fala, conversão de áudio em texto e exploração de recursos relacionados ao processamento de voz. Esse tipo de abordagem é útil para entender rapidamente o potencial da plataforma antes de partir para integrações via SDK, CLI ou API REST.

### 2. Exploração do Language Studio
No Language Studio, o foco está na análise de texto com recursos de processamento de linguagem natural. Um dos cenários demonstrados no laboratório é a análise de sentimento com opinion mining, permitindo identificar se um texto possui polaridade positiva, negativa, neutra ou mista, além de destacar opiniões associadas a entidades e aspectos específicos.

Essa etapa ajuda a compreender como serviços cognitivos podem ser aplicados em avaliações de comentários, feedbacks de clientes, reviews de produtos e outros conteúdos textuais. Na prática, isso mostra como a IA pode transformar texto não estruturado em informação útil para tomada de decisão.

## Aprendizados obtidos
- O Speech Studio facilita a experimentação de serviços de voz por meio de uma interface amigável e sem código, o que acelera o entendimento inicial da ferramenta.
- O Language Studio permite analisar textos de forma prática, identificando sentimentos e opiniões com apoio de modelos de IA prontos para uso.
- A documentação no GitHub é parte importante do desafio, porque transforma a prática em material de consulta futura e em evidência de aprendizado técnico.
